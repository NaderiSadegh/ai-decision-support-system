# Demo Screenshot Checklist

Use these screenshots to make the GitHub repo, project page, or launch post easier to scan.

## Capture

- CLI output from `make demo`.
- Swagger `POST /ask` request and response.
- GitHub Actions passing CI run.
- Optional: `reports/evaluation_report.md` showing the evaluation score.

## Where To Use Them

- README demo preview section.
- GitHub repository social preview.
- Project page.
- LinkedIn project post.

## Reminder

All screenshots should use the synthetic IncidentLens dataset only. Do not include real customer, employer, platform, token, or incident data.
